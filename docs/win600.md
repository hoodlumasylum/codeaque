# CodeAque on the Anbernic Win600

This turns a Win600 into a CodeAque handheld: Linux Mint, every emulator CodeAque supports, the
cloud gaming tiles, Handheld mode on, and CodeAque opening by itself when it starts.

> **Untested on a real Win600.** Every step below is written from the Win600's specs (AMD Athlon
> Silver 3020e, 1280x720 screen, built-in Xbox-style pad) and tested on ordinary PCs and virtual
> machines only. Please tell us what went wrong.

**No BIOS files, firmware, keys, ROMs or games are included.** Bring your own.

## What you need

* The Win600, charged (or plugged in).
* A USB stick, 8 GB or bigger. Everything on it is wiped.
* A **USB-C hub with a USB keyboard** (a mouse helps). The installer needs typing.
* Wi-Fi name and password.
* About 1–2 hours (most of it is waiting for downloads).

**Warning:** installing Linux Mint the way below **wipes the Win600's internal drive** (SteamOS or
Windows is removed). Copy anything you want to keep first.

## 1. Make the stick (on another PC)

Follow [live-usb.md](live-usb.md) steps 1–3: download the CodeAque Live USB, join the parts and
write it with Rufus. (A normal Linux Mint ISO from linuxmint.com works too.)

## 2. Start the Win600 from the stick

1. Turn the Win600 **off**. Plug the hub into the USB-C port, then the stick and the keyboard into the hub.
2. Hold **Volume Down**, press **Power**, keep holding Volume Down until a menu appears.
   * If no menu appears: turn it off and try with **Volume Up** instead (that opens the BIOS setup —
     go to the *Boot* tab, move the USB stick to the top, then *Save & Exit*).
   * With a keyboard plugged in, tapping **F7** (boot menu) or **Esc/Del** (BIOS) while it starts also works on most units.
   * From Windows instead: *Settings > System > Recovery > Advanced startup > Restart now > Use a device*.
3. Pick the USB stick (it may say *UEFI: <stick name>*).
4. If the screen is black or sideways, restart and pick **Safe graphics** in the stick's menu.

## 3. Install Linux Mint

1. In the stick's menu choose **Install CodeAque** (or *Install Linux Mint* on a plain Mint stick).
2. Language, keyboard, then connect to Wi-Fi.
3. On *Installation type* choose **Erase disk and install** (this wipes the internal drive).
4. Pick your time zone, your name and a password. Tick **Log in automatically** (so CodeAque can open by itself).
5. When it finishes, pick **Restart now** and pull out the stick when told.

## 4. Run the CodeAque Win600 installer

After Mint starts, open the **Terminal** (menu > Terminal) and type these three lines:

```
sudo apt install -y git
git clone https://github.com/hoodlumasylum/codeaque.git ~/codeaque
bash ~/codeaque/scripts/install-win600.sh
```

(Or download `install-win600.sh` from the v0.8.0 release and run `bash install-win600.sh` — it
downloads CodeAque for you.)

Type your password when it asks. It then:

1. installs CodeAque,
2. installs the emulators: RetroArch (+ cores), DuckStation, PCSX2, PPSSPP, Dolphin, Cemu, Azahar,
   melonDS, DeSmuME, mGBA, Flycast, Rosalie's Mupen GUI, mupen64plus, Mednafen, MAME, DOSBox, ScummVM,
   FS-UAE, VICE, xemu, RPCS3, Ryujinx — from Flathub, apt or the projects' own releases — plus Chrome
   (for the cloud tiles and streaming), Kodi, Moonlight and AntiMicroX,
3. sets them to fullscreen at 1280x720 with the built-in pad,
4. turns on **Handheld mode**,
5. makes CodeAque open at login.

If something fails, just run the last line again — it skips what is already installed.

## 5. Use it

* Restart. CodeAque opens in Handheld mode.
* **Cloud:** Xbox Cloud Gaming, GeForce NOW, Amazon Luna, Boosteroid… open in Chrome. Sign in with your own account.
* **Games:** *Settings > Add games* (copy them from a USB stick). BIOS you own: *Settings > Add BIOS files*.
* **RetroArch:** press **L3 + R3** for its menu; hold **Start + Select** to go back to CodeAque.
* **Leave Handheld mode:** *Settings > Leave Handheld*. Turn it on again in *Settings > Handheld mode*.

## What is untested

* Everything on real Win600 hardware: the boot keys, Safe graphics, the screen orientation, the
  built-in pad's mapping, sleep/resume, battery reading, Wi-Fi and sound drivers.
* Speed: the Athlon 3020e is slow. Expect up to PS1, N64, Dreamcast, PSP and most GameCube/PS2 2D
  games to be fine; Wii U, PS3 and Switch emulators are installed but will mostly be too slow.
* The emulator settings are written before each emulator is first opened; an emulator update could reset them.
* The installer itself was syntax-checked and its settings code unit-tested, but not run start-to-finish on Mint.
